# AITU Moodle Sync 0.2.0

Chrome/Edge extension for https://kuaabilov.github.io/aitu-student-hub/

Extract this folder, open chrome://extensions or edge://extensions, enable Developer mode and choose Load unpacked. Select the folder containing manifest.json.

Open the hub and Moodle AITU in the same browser. In Moodle: course > Attendance > All courses. Click the extension, read the table and send it to the hub. Review and confirm import in the hub.

On-demand attendance only; no background sync, passwords, cookies or API keys. Up to 30 courses. No local server. Data remains in browser storage after confirmation. Host permission covers kuaabilov.github.io; code checks the exact Student Hub path before transfer.

Online guide: https://kuaabilov.github.io/aitu-student-hub/connect.html
