Твои учебные данные

Кабинет хранит посещаемость, оценки, расписание, задания и выбранный язык в localStorage твоего браузера. Очистка данных сайта удаляет эти записи. Сохранение между устройствами и серверная учётная запись не предусмотрены.

Расширение AITU Moodle Sync читает строки открытой таблицы Attendance в Moodle AITU по твоему нажатию. Названия предметов, число занятий, баллы и процент передаются в открытую вкладку Student Hub средствами браузера. Сохранение происходит после подтверждения импорта.

Код расширения не читает пароль, cookies или API-ключи; не отправляет таблицу в сетевых запросах, URL, логи или аналитику. У него нет фонового сбора данных. Сайт получает только выбранные тобой данные.

Статические файлы сайта и расширения раздаются GitHub Pages. При открытии сайта браузер обращается к GitHub; обычные сетевые данные об этих посещениях обрабатываются по правилам хостинга. Учебные записи приложение на GitHub не загружает.

Другие приложения на том же origin kuaabilov.github.io технически относятся к тому же источнику браузера. В кабинете используются отдельные ключи хранилища от старого attendance-сайта; это разделение записей, а не отдельный домен безопасности.

Неофициальный проект, не сервис университета. Открытый исходный код.
