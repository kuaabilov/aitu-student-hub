# AITU Student Hub

Отдельный студенческий кабинет: attendance, GPA, расписание, дедлайны и перенос посещаемости из Moodle AITU через расширение Chrome/Edge.

[Открыть Student Hub](https://kuaabilov.github.io/aitu-student-hub/)

## Возможности

- RU / ҚАЗ / EN, адаптивный интерфейс.
- Таблица предметов и быстрые калькуляторы пропусков.
- GPA с весом по кредитам, недельное расписание, задания.
- Ручной импорт таблицы и календаря `.ics`.
- AITU Moodle Sync: чтение открытой таблицы All courses по кнопке, предпросмотр и подтверждение.

Это отдельный проект от `kuaabilov/Kua`. Локальный сервер конечному пользователю не нужен. Данные хранятся только в браузере пользователя; облачной учётной записи и межустройственной синхронизации нет.

## Подключение Moodle

Скачай архив `downloads/aitu-moodle-sync.zip`, распакуй и установи папку через **Load unpacked** в режиме разработчика Chrome/Edge. Подробности в [инструкции](connect.html).

В одном браузере открой кабинет и Moodle AITU, войди в Moodle. Перейди: предмет → Attendance → All courses. Нажми расширение → Считать таблицу → Передать в кабинет → Импортировать.

Расширение не использует API и не читает пароль/cookies. Оно переносит только предметы и attendance, до 30 строк. Обновление по кнопке, не фоновое. На телефоне без поддержки расширений доступны ручной ввод и импорт календаря.

Число занятий за весь триместр нужно указать вручную. Эквивалент пропусков может отличаться от фактического числа отсутствий из-за частичных отметок. Порог посещаемости настраивается пользователем по правилам курса.

## Приватность и ограничения

См. [обработку данных](privacy.html). В репозитории нет личных учебных записей. Исходники расширения находятся в `moodle-extension/`; ZIP содержит ту же версию. Расширение не опубликовано в магазине и требует ручной установки. Вёрстка Moodle может измениться, поэтому парсер может потребовать обновления. Сквозная передача в опубликованную версию требует проверки после её развёртывания и установки расширения.
